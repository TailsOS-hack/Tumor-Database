# Grounded Report Maker

The GUI now uses a deterministic grounded-report path instead of asking an LLM to interpret the MRI image and invent a full radiology report.

## Why This Exists

The CNN classifiers can provide:

- predicted class label
- model confidence
- model used
- internal validation context

They cannot provide:

- lesion size
- lesion location
- contrast enhancement
- edema
- midline shift or mass effect
- hippocampal volume
- cortical atrophy measurements
- vascular, orbital, sinus, bone, or soft-tissue findings

The report maker therefore writes only what is supported by structured evidence and marks unsupported findings as not assessed.

## How To Use

Command line:

```bash
python -m src.grounded_report --prediction glioma --confidence 97.2% --model-used "Brain Tumor Model" --format markdown
```

From hierarchical inference JSON:

```bash
python -m src.hierarchical_inference path/to/mri.png > prediction.json
python -m src.grounded_report --prediction-json prediction.json --format html --output grounded_report.html
```

GUI:

```bash
python -m src.radiology_report_gui
```

The GUI still allows optional AI auto-detection for basic acquisition metadata, but its prompt now refuses diagnosis/pathology inference. The report itself is generated by `src.grounded_report` without LLM image interpretation.

## Optional LLM Use

An LLM can be used only as a style pass over the deterministic report, using `build_llm_style_prompt()`. It must preserve the same JSON keys and facts. If it adds findings, measurements, locations, or diagnoses not present in the structured evidence, reject the output and use the deterministic report.
